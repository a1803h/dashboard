# Drive Dashboard · Android v1.0.0-alpha1

Нативный автомобильный дашборд на **Kotlin + Jetpack Compose**, по макету Figma:
https://www.figma.com/design/PtELJuuF3ol49vSWEyu1vL/Untitled?node-id=0-1

## Возможности версии 1

- GPS-спидометр (Android LocationManager/GNSS, **без интернета**). Пять кружков GPS пустые, если координаты недоступны; после фикса показывают условное качество по числу спутников, участвующих в решении.
- Цвет обводки текущей скорости: белый до 60 включительно, зелёный (60,80), жёлтый [80,90), красный от 90 км/ч.
- Средняя скорость — голубая; приблизительная передача и условные RPM рядом со скоростью.
- До 6 редактируемых передач: для каждой минимальная/максимальная скорость и минимальные/максимальные обороты; по умолчанию активны 1–5, 6-я пустая.
- Передачи **рекомендованные**, а не реально включённые: расчёт исключительно по GPS-скорости. При повышении передача переключается на пороге, при понижении — с задержкой 1.5 км/ч для защиты от дрожания.
- RPM вычисляются линейной интерполяцией внутри диапазона выбранной передачи. На последней передаче при превышении диапазона расчёт может расти до программного ограничения 8000 RPM. Это не показания двигателя.
- Валидация настроек: пустая, незаполненная, некорректная и пересекающаяся передача неактивна. Черновые значения сохраняются автоматически.
- Поездка: ввод общей дистанции (км), расчёт пути GPS, остатка, прогресс, прошедшее время, ориентировочное прибытие по средней скорости, Reset/Edit, автосохранение между запусками.
- Сохранение до 8 закреплённых приложений (выбор, порядок, запуск).
- Выбор медиаплеера или автоопределение активной Android MediaSession. Проигрывание, пауза, предыдущий/следующий, перемотка; shuffle/repeat там, где плеер поддерживает стандартное API.
- Регулятор громкости медиа, яркость только окна дашборда (без системной привилегии), режим с включённым экраном.
- Вертикальный интерфейс по макету. Содержимое прокручивается на устройствах с недостаточной высотой.

## Сборка

Откройте корневой каталог проекта в **Android Studio**. Установите Android SDK 35, JDK 17, Gradle 8.9, затем Sync Project и **Build → Build APK(s)**. Debug APK после успешной сборки: `app/build/outputs/apk/debug/app-debug.apk`.

Для CLI при установленном Android SDK и Gradle 8.9:

```bash
gradle :app:assembleDebug
```

Файл `.github/workflows/android.yml` автоматически собирает debug APK на GitHub Actions после загрузки проекта в новый репозиторий. В Actions → Build Android APK → Artifacts будет ZIP с `app-debug.apk`. **Не подписанный релиз**, а отладочная сборка для тестирования.

**Важно:** среда генерации проекта не содержит Android SDK/Gradle и не имеет доступа к репозиториям зависимостей. Поэтому здесь доступна проверка автономного Kotlin-ядра, но не фактическая Android-сборка или запуск на устройстве. Это исходный проект, не подтверждённый рабочий APK.

## Разрешения

- `ACCESS_FINE_LOCATION` — скорость и расстояние по GPS, доступ только пока приложение открыто.
- Доступ к уведомлениям Android (Notification Listener) — требуется **только** для получения активных медиасессий сторонних плееров. Содержимое сообщений не считываем, не отображаем и не сохраняем. Панель уведомлений не входит в V1.
- Поиск запускаемых приложений ограничен `MAIN`/`LAUNCHER` через `<queries>`.

В версии 1 **нет** панели уведомлений (план V2), карт и навигации (план V3), OBD и фонового отслеживания после закрытия приложения. Подсчёт расстояния активен, когда дашборд открыт и есть валидный GPS. Если свернуть/закрыть приложение, поездка сохраняется, но пройденные в это время метры не учитываются.

Время прибытия — ориентировочное, потому что нет маршрутизатора и данных о пробках. Предполагается заранее заданная общая длина поездки.

## Проверка логики передач без Android SDK

При установленном Kotlin CLI:

```bash
kotlinc app/src/main/java/tj/umed/drivedashboard/GearLogic.kt core-tests/Main.kt -include-runtime -d /tmp/gear-tests.jar
java -jar /tmp/gear-tests.jar
```

Проверяется отсутствие шестой передачи по умолчанию, переключение на границах, гистерезис, расчёт RPM, активация заполненной шестой и отключение некорректных диапазонов.

## План версий

- **V1:** приборная панель, настройки, GPS, расчёт RPM/передачи, медиаплеер, ярлыки приложений, поездка.
- **V2:** отдельная панель уведомлений.
- **V3:** карта и навигация.
