# Drive Dashboard · Android v1.1.0-alpha1

Нативный автомобильный экран на Kotlin / Jetpack Compose, переработанный по актуальному макету:
https://www.figma.com/design/hQgk5FZRL6ShbtnAiIcd8j/Untitled?node-id=1-540

## Интерфейс

- Полноэкранный портретный экран без системного статус-бара и навигационной полосы.
- Шесть плиток Figma: «Осталось», «Пройдено», «Прибытие», «Прошло», «Скорость», «Расстояние».
- Сверху время, пять индикаторов GPS, заряд телефона; ниже регулировка яркости текущего окна.
- Восемь слотов с иконками реальных установленных приложений, а не цветными заглушками.
- Настройки с кнопками «Выбрать» и «Сортировать» как в Figma; диалоги выбора и порядка до восьми приложений.
- Макет масштабируется по ширине на основе дизайнерского фрейма 1440 × 3200. На коротких экранах можно прокрутить.

## Логика поездки

- Одно нажатие на «РАССТОЯНИЕ»: ввод общей дистанции в км. При изменении расстояния начинается новая поездка.
- «Скорость» показывает текущую скорость GPS в км/ч, не среднюю скорость.
- «Пройдено» — GPS-расстояние только во время активной автомобильной поездки; «Осталось» = max(0, всего − пройдено).
- «Прошло» — минуты активной поездки, без времени автоматической или ручной паузы.
- «Прибытие» — оценка времени до конечного пункта в минутах по средней скорости всей записанной поездки. Пока данных мало, показывает прочерк. Это НЕ дорожная навигация и не фактическая маршрутизация/пробки.
- Автостарт при событии IN_VEHICLE в Google Play services Activity Recognition. Автопауза при WALKING/ON_FOOT. При отсутствии этих сигналов используется GPS-классификатор: 14+ км/ч на протяжении 5.5 с = автомобиль; 1.5–8 км/ч на протяжении 12 с = ходьба. Стоянка на светофоре (0 км/ч) **не** считается ходьбой.
- Двойной тап по «СКОРОСТЬ» включает принудительную паузу или принудительное продолжение поездки. Длительное нажатие возвращает автоматическое определение.
- Время и дистанция сохраняются между запусками. Обновления GPS работают пока экран приложения открыт; в фоне GPS не записывается. Скорость обновляется и в режиме паузы.

**Ограничения:** GPS-классификатор не может всегда точно отличить машину от велосипеда или автобуса, а скорость/качество спутников зависят от условий. Для Activity Recognition нужны Google Play services и разрешение на физическую активность; при отсутствии сервиса будет работать GPS-режим. Фоновое отслеживание и полноценная навигация не реализованы.

## Сборка

Android Studio, JDK 17, Android SDK 35, Gradle 8.9; команда:
```bash
gradle :app:assembleDebug
```

CI: Actions → Build Android APK → Artifacts → DriveDashboard-debug-APK. Собранный в Actions debug APK предназначен для тестирования, не для выпуска в магазин.

Шрифт MiSans Latin загружается в GitHub Actions напрямую с Xiaomi и встраивается в APK. Сам шрифт отдельно не распространяется.
